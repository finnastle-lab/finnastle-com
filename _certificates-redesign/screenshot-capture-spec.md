# Screenshot capture, treatment, captions and alt

Four genuine screenshots, still to be supplied. No image here has been fabricated or pulled
from an authenticated session. The capture directions are grounded in what the article says,
not in observations of the interfaces.

## Shared treatment

Capture at native resolution, 1402px long edge or greater; a larger original can be reduced.
Use the product's normal light theme if it has one. Crop browser tabs, URL bar and OS chrome.
Keep the tool identity and the task/result together. No device frame, perspective, shadow,
extra accent or artificial chrome. Preserve functional colours and original text. **If the
real interface conflicts with the brand palette, flag the conflict rather than recolouring
your way out of it** — the whole argument of the article is that these things exist.

Place the useful crop flat on `#FAF9F6`, with at most 24–32px padding, and none where the real
page already supplies whitespace. Do not stretch. Use portrait 1122 × 1402 only for a
naturally portrait view; landscape keeps its meaningful native aspect ratio at roughly a
1402px long edge. Check readable labels at 700px and 350px. If a full screen shrinks into
noise, use a tighter real crop.

The filmic dashed tab was not supplied with the pack: omit it. There is no standalone FA
signature in the pack: do not invent one.

## Markdown insertion

Replace each commented screenshot slot only once the real PNG, the literal alt text and the
course pairing all exist. Use the pattern exactly — image, blank line, italic caption:

```
![Literal description of the real screenshot](../../assets/writing/four-things-i-built/almanac.png)

*Certificate: AI for Data Analysis. Built: Almanac.*
```

Each screenshot follows its existing tool paragraph. Genuine screenshots need no "machine-made"
disclosure — that device belongs to the Pope essay, where the pictures were generated. If a
screen happens to contain generated content, describe that content accurately.
